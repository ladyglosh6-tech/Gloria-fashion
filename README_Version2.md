# Lady Glosh — Fashion & Design (Demo)

A small single-page demo website called "Lady Glosh" that links to worldwide fashion brands (Nike, Zara, Adidas, H&M, Uniqlo, Gucci) and includes a unique "quick deck" slide component for Sign In, Register, Feedback and Sign Out.

This is a front-end demo only (no server). Sign-in state and feedback are stored in browser localStorage to demonstrate flows.

Features
- Responsive modern layout with glassmorphism + gradient styling.
- Floating "Quick" button that opens a slide-in deck (right side) for fast actions.
- Sign In / Register forms (client-side demo: stored locally).
- Feedback form saved locally and shown in the deck.
- Quick links to major brand websites (open in a new tab).

How to run
1. Save the files (index.html, styles.css, script.js) in the same folder.
2. Open `index.html` in your web browser.
3. Click the floating "Quick" button (bottom-right) or "Quick Access" in the nav to open the slide deck.
